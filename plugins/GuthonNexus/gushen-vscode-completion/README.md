# Guthon Nexus

谷神 API 源码开发插件，在 var 根目录窗口选择工作区，完成登录、按子系统拉取、源码浏览与受控编辑。当前源码保存在唯一的 checkout 中，上传前比较平台版本，上传后逐项回读。

支持官方风格的 API 签名和文档提示，同时保留 Nexus 的关键词、方法名及缩写补全；提供定义跳转、PAGE XML/JSON 编辑、字段集合 JSON、继承展开、草稿恢复、SCM 和 Quick Diff。

侧栏采用“项目总览＋当前项目＋当前项目源码”。总览按名称、别名或 key 搜索，点击项目行切换当前窗口目标；卡片与源码树联动，IDE 继续打开 var 根，已打开的标签页和草稿保持原归属。卡片提供常用操作，低频功能位于原生“…”菜单。源码按页面、过程函数、表、视图和系统脚本分类。选择范围后自动同步并刷新；取消范围有本地修改、草稿或未登记文件时先停止，处理并重选后再备份清理。新数据目录使用 schemaVersion 3，保留已有 API schema 2；完整旧 YAML 可只读解析。SVN/DATABASE 项目按当前模式显示更新、源码、本地修改和操作记录。清单 SVN 支持受控分块编辑和提交审阅。DATABASE 使用 readonly 与 Workcopy，交付入口生成本地材料。配置错误有可点击诊断行和刷新入口，全局配置错误清除可操作目标。配置升级和源码迁移属于 P4。

首次使用：设置 GuthonCodeTool 运行入口与显式数据目录，打开 var 根目录，创建并选择工作区，在当前窗口登录并选择范围，再更新源码。每个工作区包含 checkout、context、runtime 和 docs；根 rules 保存共用开发规范。Codex 可打开具体工作区目录，通过同一 Git 根读取根 AGENTS.md。浏览器增强按需启用；数据库诊断使用独立只读目标。

上传前可按名称、类型及路径勾选文件并查看差异；源码树支持仅展示过滤、物理文件操作和资源管理器状态提示。继承标记及全局事务调用支持导航，本地函数支持注释悬停；物理 PAGE 的原生编辑器复用现有草稿。

从工具设置生成 MCP 客户端配置，预览后合并并检查连接；独立 MCP 在线操作复用对应 Nexus 项目的登录会话。操作步骤见使用手册，功能批次及验证边界见[功能吸收记录](../../../docs/api-sync/official-adoption.md)。

Nexus 可检查 Open VSX 官方来源包，校验并切换兼容的补全资源，用临时编辑器说明变化与回退结果。同步、设计器等执行协议的升级随经过适配验证的 Nexus 版本发布。

`api-sync` 说明对应该分支代码及构建产物，正式发行包的功能以对应发行说明为准。源码、离线 HTML 手册和配置参考见 [GuthonCodeTool 仓库](https://github.com/SidWuu/GuthonCodeTool/tree/api-sync)；完整实现与验证边界见仓库的 `docs/api-sync/feature-matrix.json`。
