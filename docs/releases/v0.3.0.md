# GuthonCodeTool v0.3.0

工具与 Chrome Bridge 版本为 0.3.0，Guthon Nexus 扩展版本为 2.4.0。应用、VSIX、Bridge 和 Testing Skill 请使用同一发行批次。

## 新功能

- 有界源码读取与批读、索引健康度、稳定游标、正文/标签检索、索引变更、跨工作区搜索、读写表与区域摘要、影响图和源码地图。
- Nexus 导出私有 AI 上下文文件；提供正式数据库目标向导、诊断历史、CSV/XLSX、模板案例草稿、开发/测试计数对比、估计计划和只读计划执行。
- 编辑租约续期/释放、字段标签更新、操作日志巡检、拉取历史分页/导出/可恢复归档、最近对象普通重拉、并行导出及索引协作式取消。
- 快速打开、过程函数字面量补全、精确分享链接、Nexus 反向定位、有界页面快照及鉴权事件流。
- 显式 JSON 输出使用 apiVersion=1，保留现有顶层字段；支持统一文本、表格和 CSV 格式。
- 内置独立 Ed25519 公钥，发行附件使用签名与哈希验证；普通使用者无需配置密钥。显示 Nexus 与后端各自的构建标识。

## 修复

- 工作区必须使用明确的 toolHome 和 workspaceKey；修复命令参数、跨工作区路由、坏配置隔离、同步状态与缓存竞态。
- 强制覆盖需要完整工作区确认；Workcopy 修改有备份与恢复路径。自动暂存只包含本次生成的新文件。
- 改进 MySQL/PostgreSQL/Oracle 只读事务、字面量与 CTE、业务 schema、结果完整性、凭据来源、连接释放与错误阶段。
- 修复 SVN/MCP 编辑租约、当前源码校验、稳定分页、部分索引、继承静态解析、身份冲突及分组提交回执恢复。
- Bridge 增加本机配对和来源验证，限制导出目录、文件类型及权限；改进 MV3 作业恢复、进程停止、SCM 状态、缓存与更新回退。

## 重构

- 分离运行路径、工作区注册、Workcopy 生命周期、共享持久化、DATABASE 镜像事务及数据库命令编排。
- SVN CLI 按职责分派，共用会话、编辑日志和物理写回内核；删除失效的转发脚本，复用 PAGE 投影。
- Python 与 Node 共用命令元数据、超时、读写分类和别名；增加注册/菜单及生成副本检查。

## 升级与使用

- 新增语义与正文检索能力需要完整重建旧工作区索引。重建只更新索引；SVN 远程更新仍是独立命令。
- Nexus 启动 Bridge 后，从 Nexus 复制配对令牌并在 Chrome 弹窗保存。两端端口保持一致，不在平台页面输入令牌。
- 源码保存仍只写本地工作副本，SVN 提交、平台发布和业务运行分别验证；Oracle EXPLAIN 计划表写入不开放。
- 推荐同步命令为 source-sync、source-sync-full、workspace-sync、index-rebuild、index-init，旧命令继续可用。
- 仅支持 Apple Silicon Mac 与 Windows x64。平台交互可按 [人工验收清单](v0.3.0-platform-acceptance.md) 自行验证。
