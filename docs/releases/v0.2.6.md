# GuthonCodeTool v0.2.6

本版本更新 Guthon Nexus 运行入口选择、macOS 发行包布局，并发布 Windows 安装子页面。

## 下载内容

- Windows x64 应用：`GuthonCodeTool-windows-x64.exe`
- macOS Apple Silicon 应用：`GuthonCodeTool-macos-arm64.zip`
- Python 调试脚本及依赖清单：`GuthonCodeTool-python.pyz`、`GuthonCodeTool-python-requirements.txt`
- Guthon Nexus 2.3.2：`guthon-nexus-vscode.vsix`
- Guthon Bridge：`GuthonCodeTool-chrome.zip`
- Guthon Testing Skill：`guthon-testing.zip`
- 应用校验文件：`GuthonCodeTool-checksums.txt`

## 本次变更

- Nexus 的“当前入口”可重新选择并验证当前运行模式的入口；“本地数据目录”可直接切换工作空间。发行应用选择时检查版本命令与临时数据目录自检。
- macOS 发行包使用固定顶层 `GuthonCodeTool` 布局；Nexus 更新器兼容此前的 `dist/GuthonCodeTool` 包。
- 使用手册新增 Windows 安装步骤子页面，配有已遮盖设备标识及业务身份的操作截图。公开站点不包含原始内部截图或业务连接资料。

## 验证边界

源码测试、公开文档检查和发行工作流构建结果分别核验。Windows 已安装环境、实际工作区索引最终状态与业务平台运行仍需在目标环境验证。
