## 核心能力

GuthonCodeTool 是谷神开发平台增强工具，面向谷神开发，将源码、搜索、编辑、差异检查和交付流程集中到本地支持插件的类 VS Code 编辑器中，支持 macOS 和 Windows。

- 支持 DATABASE 源码 / SVN 源码本地双模式开发。
- 通过 Guthon Nexus VS Code 插件统一管理产品、项目、配置、源码与本地工作区。
- 支持快速检索 PAGE、过程函数、表读写和调用关系等信息。
- 封装 SVN 功能，提供安全编辑、差异查看、远程更新、冲突合并与 SVN 提交。
- 通过 Guthon Bridge Chrome 插件联动谷神平台与本地 VS Code。
- 支持谷神源码调用事实索引，为本地 AI 提供精准源码上下文和调用关系。
- 通过 Guthon Guard 统一团队 AI 开发规范门禁、Linter 和 Git Hook，提高开发一致性。
- 提供使用手册、全功能说明和问题解决中心，便于快速上手。

## 本次变更

- 简化产品和项目创建流程，选择 SVN 或 DATABASE 后即可生成对应 Nexus。
- 将 SVN 登录、checkout 配置导入和范围编辑集中到目标工作区。
- 支持多行粘贴 checkout 地址，自动生成公共 URL 和去重后的精确 scope。
- 增加产品和项目右键删除，并在确认后清理对应文件与配置。
- 单项 SVN scope 无权限或不存在时记录并跳过，继续检出其余源码。
- 不同数据源中的同名数据库对象按 schema 身份分别索引。
- 根据根目录中文名称及 `index.md` 内容推断业务分组；证据不足时独立成组，同时保留 `systems.include.mappings` 兼容能力。
- 修正 Guthon Nexus 树布局、工作区加载及 SVN 配置交互问题。
- Guthon Nexus 升级至 2.2.5。
