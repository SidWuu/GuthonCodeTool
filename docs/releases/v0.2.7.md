# GuthonCodeTool v0.2.7

本版本增加 SVN 项目继承源码的分层读取与只读展开视图，并修复大仓库索引等待时间和项目删除前的文档提示。应用、Nexus VSIX、Bridge 和 Testing Skill 请使用本次 Release 的同批附件。

## 下载内容

- Windows x64 应用：`GuthonCodeTool-windows-x64.exe`
- macOS Apple Silicon 应用：`GuthonCodeTool-macos-arm64.zip`
- Python 调试脚本及依赖清单：`GuthonCodeTool-python.pyz`、`GuthonCodeTool-python-requirements.txt`
- Guthon Nexus 2.3.3：`guthon-nexus-vscode.vsix`
- Guthon Bridge：`GuthonCodeTool-chrome.zip`
- Guthon Testing Skill：`guthon-testing.zip`
- 应用校验文件：`GuthonCodeTool-checksums.txt`

## 本次变更

- Nexus 默认打开可编辑的项目 `.gss` 或 PAGE 项目事件原文；“查看展开后的继承源码”显示只读派生视图，并标明项目、产品来源。`.inherit.gss` 作为产品物理源记录，不再显示为另一个可编辑的过程函数。
- MCP `read_inherited_source` 以精确身份、双层哈希和有界分段返回项目原文、产品原文、继承状态、展开结果及来源位置。过程函数移除有效 `inherit` 标记时，预览与写入必须复核产品原文哈希。无法确认语义的标记不会自动物化。
- SVN 检出、更新和重建索引使用适合大仓库的等待时间，并在扫描过程中持续报告进度，避免扫描尚未结束就将结果视为超时。
- 删除项目时，若项目 `docs/` 下存在文件，确认框会提示先检查是否需要备份。
- 使用手册、全功能说明与 QA 同步更新。

## 使用与验证边界

升级后须对相关 SVN 工作区完整重建一次本地索引。展开视图不能直接保存；编辑只走项目原文的现有受控流程，本地写入不等于 SVN 已提交。

Python 全量 327 项通过（2 项按条件跳过），Nexus 183 项和 Bridge 42 项通过；本机 zipapp 与 macOS 应用在临时数据目录完成发行冒烟。一个真实 SVN 项目已重建本地索引并只读抽样过程函数与 PAGE 继承脚本，项目 SVN 工作副本保持无改动。Windows 安装态、真实项目的 Nexus 展开交互、AI 自主路由和谷神平台业务运行仍需分别验收。
