# GuthonCodeTool v0.2.5

本版本整合谷神开发平台与方言开发便利性、SVN 源码定位与受控编辑、安装验收和文档修订。应用、Nexus VSIX、Chrome 扩展和 Testing Skill 请使用本次 Release 的同批附件。

## 下载内容

- Windows x64 应用：`GuthonCodeTool-windows-x64.exe`
- macOS Apple Silicon 应用：`GuthonCodeTool-macos-arm64.zip`
- Python 调试脚本：`GuthonCodeTool-python.pyz` 与依赖清单 `GuthonCodeTool-python-requirements.txt`
- Guthon Nexus：`guthon-nexus-vscode.vsix`
- Guthon Bridge：`GuthonCodeTool-chrome.zip`
- Guthon Testing Skill：`guthon-testing.zip`
- 应用校验文件：`GuthonCodeTool-checksums.txt`

## 开发便利性

- Bridge 弹窗和谷神页面左下角按钮组均可将当前 PAGE 或过程函数定位到 Nexus。PAGE 按完整编码查找；过程函数按包名和函数名查找。Nexus 要求当次选择 SVN 工作区，并核对同名多候选的源码身份。
- 优化弹窗定位按钮样式。左下角按钮组在开发页签出现时先显示，再异步确认工作区模式；异步页签变化可立即触发刷新，30 秒轮询只作兜底。
- Nexus 虚拟 GSS 提示重复的本地 `#function` 并补全当前文档的 `@` 调用；PAGE 字段集合提示重复 `fieldId`，补全当前集合及索引中其他集合的字段，并显示来源。
- PAGE 可按字面前缀发现同一命名空间中其他 PAGE 的字段；PAGE 和过程函数可预览有界的表访问、字段关系、逻辑事实或调用线索，并跳转到对应源码证据。候选关系均保持未验证标记。

## SVN 与 MCP

- PAGE 支持同一已识别字段集合内的单字段新增或拷贝，生成新字段身份，沿用编辑租约、预览、幂等写入和操作恢复。受控预检比较候选前后的表访问与显式字段关系，并绑定源码路径、工作副本及哈希。
- 修正 Nexus `page-query` 与 ToolHost 只读请求类型不一致的问题，恢复 PAGE 定位、语义浏览和相关查询。
- Nexus 提供索引缺口的单 PAGE 刷新或工作区重建入口；源码影响预览按路径、命名空间和 working copy 复核，不能确认时拒绝归因。
- SVN 提交成功并取得 revision 视为本次源码交付成功；交付回执保留 revision 与文件范围。编译、发布和业务运行仍分别取证。

## 安装、文档与构建

- 工作区树显示当前运行入口和数据目录；开发模式与调试模式分别给出准确的更新提示。修复 DATABASE 单源码拉取索引连接的关闭边界。
- 使用手册、全功能说明和 QA 更新安装、定位、索引恢复及各功能故障处理。README 末尾的文档区只保留在线文档入口。
- Pages 发布前检查三份公开 HTML 的脚本、链接、QA 条目和常见私有路径；Release 构建增加临时数据目录的应用与 zipapp 冒烟检查。新增 macOS/Windows 安装后实机验收清单。

## 验证边界

源码自动化检查、已安装 Nexus 的本地命令定位与受控样例读取均已执行。Chrome 外部协议按钮、Windows 安装态、远端 SVN 提交、平台编译及业务运行仍需在相应环境验证；本版本没有修改私有业务源码或数据库。
