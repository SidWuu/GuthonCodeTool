## 本次变更

- 新增 SVN MCP stdio 服务，默认提供 24 个工具（14 个只读、10 个受控编辑与恢复），支持显式 `--read-only`。服务推荐别名为 `guthon-svn`，既有 `guthon-page` 客户端别名仍可指向同一入口。
- PAGE 支持按稳定语义节点查询、读取和受控修改脚本/SQL 字符串；过程函数支持按完整源码身份有界读取、查询调用方、预览与受控修改。
- 共用现有 SVN working copy 授权、编辑租约与写回内核；写入记录操作状态、幂等键、索引同步和 SVN diff 核验，仅修改本地文件，不自动提交 SVN。
- Nexus 增加 PAGE 语义节点浏览入口；使用手册补充 Codex、ZCode、CodeBuddy 配置，以及过程函数修改流程和目录入口。

## 使用边界

- MCP 当前仅支持已配置的 SVN manifest 工作区；DATABASE 源码的 readonly/workcopy 写入不在本次范围。
- PAGE 任意 JSON 结构、字段增删移动及反射组写入未开放。过程函数写入限定完整身份确定的一份授权物理文件，不提供跨文件原子批量写入。
- 测试夹具与构建检查不等于真实业务 SVN、谷神平台运行或已安装客户端验收；写入后仍须人工审阅 SVN diff。
