# 0.3.0 谷神开发平台人工验收

此处的“平台”指谷神开发平台；交互是浏览器、Chrome Bridge、Nexus 和本地工具之间的定位、状态与任务恢复。使用开发或测试环境的已配置工作区，不需要提交 PRD SVN 或修改业务数据。

## 准备

- 核对工具版本 0.3.0、Nexus 版本 2.4.0及插件构建标识；用户已有扩展安装不自动代表版本已更新。
- 在 Nexus 启动 Bridge，复制配对令牌到 Chrome 弹窗，核对端口与连接状态。不要将令牌输入平台页面或发给同事。
- 打开一个已配置工作区对应的开发平台页签，确认 Chrome 当前识别的工作区正确。

## 平台定位到 Nexus

1. 打开一个 PAGE 或过程函数，点击“在 Nexus 中定位”。
2. 确认本地打开的是同一工作区、PAGE ID或包名/函数，未误选其他工作区的同名对象。
3. 索引不存在、过期或存在多个候选时，应有明确提示或候选选择，不自动猜测。

## Nexus 反向定位到平台

1. 在源码树选择一个 PAGE 或过程函数，执行“在谷神平台定位源码”。
2. 确认浏览器打开正确的页面或函数，数据源身份一致。
3. 打开两个候选平台页签，再执行定位；应要求选择目标页签。
4. 关闭平台页签或切换数据源后，旧上下文应过期或被拒绝，不自动重放定位指令。

## 多工作区与页面快照

1. 打开两个属于不同工作区的平台页签，分别确认扩展显示的工作区。
2. 在其中一个 Nexus 工作区执行定位，确认不会跳转另一个工作区。
3. 切换平台页面、选中页签或编辑器焦点后，元数据上下文应更新。
4. 页面快照默认不包含脚本正文、SQL、选中文字、密码或本机路径。

## 拉取任务恢复

1. 对一个测试对象执行普通拉取，任务进行期间关闭扩展弹窗，再打开“查询待恢复任务”。
2. 确认查询的是原任务，结果正常显示，没有重复发起拉取。
3. 若 Bridge 在任务中重启，应明确显示结果未知并要求核验，不自动重做。
4. “最近拉取对象”再次拉取使用新请求；原来的强制覆盖确认不应被复用。

## 新增入口抽查

- 导出 AI 上下文后，确认文件位于当前工作区 context/ai，默认只有有界索引摘要；正文只在显式选择后加入。
- 拉取历史分页或导出应固定快照。归档前应显示预览并要求完整工作区键；共享 Bridge 日志不应被清理。
- SVN“重建索引”取消后应给出最终取消或完成结果，原索引仍可查询；它不等同于取消 SVN update/commit。
- 正式数据库目标向导应明确采集系统、数据源、表范围、租户与身份证据；仅修改配置并探测连接，不执行业务写入。
