# GuthonCodeTool v0.2.8

本版本改进 SVN 项目继承源码的 Nexus 编辑体验。Guthon Nexus 扩展版本为 2.3.4；应用、VSIX、Bridge 和 Testing Skill 请使用本次 Release 的同批附件。

## 本次变更

- 打开项目过程函数或 PAGE 项目脚本时，直接在可编辑标签页展示展开后的项目与产品源码。产品段使用可辨认的低饱和度整行蓝灰背景，项目段使用更浅的背景；独立的只读来源视图仍可用于核对原文位置。
- 编辑器 Quick Diff 的基线同步展开继承源码，产品段不会被误标为本地修改。SVN 物理差异仍显示真正写入项目文件的内容。
- 只修改项目段后保存，物理项目源码仍保留 `@inherit`。修改产品段后保存，完整候选只写入项目文件，并在写入前核对产品源码哈希。
- 对 `return @inherit();` 等无法自动证明控制流等价的写法，修改产品段后保存时要求显式核对控制流。
- 继承内容读取时检查项目原文、产品哈希和索引快照；读取期间源码变化会中止展开。
- 继承文档保存后定向更新该文件索引，后续重新打开仍能读取最新两层来源。

## 使用与验证边界

旧 SVN 索引需要完整重建一次。Nexus 保存只写本地项目 checkout，不等于 SVN 已提交；保存后请审阅 SVN diff。产品物理文件继续保持只读。

Python 全量 329 项通过（2 项按条件跳过），修改保存链路后 SVN 工作区 94 项及继承专项 5 项通过；Nexus 190 项、Bridge 42 项通过。Python zipapp 与本机 macOS 应用均在临时数据目录完成发行冒烟。真实 VS Code 安装态的背景显示、编辑和 Quick Diff 交互仍需安装本版 VSIX 后验收。
