# 官方开发插件功能吸收

本记录对应 `api-sync` 的三批实现，以核验过的官方 1.0.11 公开包为功能比较基线。源码实现、隔离回归、安装后的 IDE、平台保存回读及业务运行分别记录；本分支未发布，不自动签入、编译或执行数据库结构变更。

| 批次 | 项目 | 当前实现与验证重点 |
|---|---|---|
| 第一批 | 统一源码名称与描述 | 下载保留表名、视图名、脚本用途；共用名称派生用于索引、搜索及上传，兼容旧接口缺少描述 |
| 第一批 | 上传审阅 | 原生多选、业务名称/类型/路径、逐项差异、取消、选中项哈希核对及逐项回执 |
| 第一批 | 继承导航 | 原文标记跳转、展开产品段的只读来源入口；核对父层哈希与只读属性 |
| 第一批 | 事务调用导航 | 补齐全局事务过程与线程调用；多行静态目标进入调用索引，动态目标单独标记 |
| 第一批 | MCP 会话 | 独立进程的在线操作委派到对应 Nexus 会话；测试项目隔离、退出、关闭与无自动重放 |
| 第二批 | MCP 配置向导 | 实际运行入口、JSONC 预览合并、保留其他服务和注释、备份、工具发现与在线只读检查 |
| 第二批 | 源码树过滤 | 只改变展示，保留节点及父链，不改变下载、索引或上传集合 |
| 第二批 | 本地函数悬停 | 声明与调用共用签名和紧邻注释；不将隔开的注释误归属 |
| 第二批 | 资源管理器状态 | 复用源码状态、名称及目录汇总；与 SCM 使用同一事实来源 |
| 第二批 | 文件操作 | 复制名称、绝对/相对路径、系统中显示；虚拟分块解析到所属已登记物理文件 |
| 第二批 | 原生 PAGE 编辑器 | 重新打开方式与资源管理器右键；复用已有会话、草稿、保存和恢复，不创建第二套源码 |
| 第三批 | 官方版本差异 | 比较命令、编辑器、语言声明、可识别接口、最低版本和 API 资源；分别说明已有对应、待核验、无需采用与生效状态 |

执行依赖为名称先于审阅，MCP 会话验证先于配置向导。每批补齐行为测试及受影响的手册、全功能参考和可搜索 QA。Windows 安装入口及依赖没有变化，因此不增加 Windows 安装步骤。

官方资源更新只自动切换通过兼容检查的补全和悬停数据。命令、设计器、源码协议和语法变化需要 Nexus 适配；更新报告中的已有对应入口不代表新版协议或真实平台验收。官方删除菜单的当前处理只是提示到平台操作，该取舍绑定已审阅基线，不能自动延续为未来版本的结论。

私有目标、源码基线、平台回执与恢复材料保存在具体任务的私有验证目录，不进入公开仓库。真实上传结果未知时先核对原操作，不重发。源码保存回读也不等同业务执行、最终签入或发布；Windows 实机与未执行的业务验证继续保留验证边界。

## 验证结果

三批实现及相关回归已完成。验证覆盖源码名称全链路、上传选择/取消/变化保护、物理及虚拟继承导航、事务调用索引、独立进程 MCP 会话与配置、树过滤、文件操作和原生 PAGE 草稿复用。已在隔离配置安装 VSIX 并验证 CodeBuddy CN 的实际入口。

获准开发子系统的两个源对象已完成本地保存、上传与独立回读。实机发现数据源字段/主键省略零小数精度的规范化差异，已补齐有限比较及反例回归，并仅回读原操作恢复回执，未重复保存。恢复原文和私有回执由任务验证目录保存；本记录不包含业务源码或目标身份。

文档结构、链接和 QA 关键词已检查。本地 HTML 浏览器显示因浏览器文件协议策略未验证；Windows 实机、在线设计器 iframe 的实际保存、最终平台签入/编译/发布和业务运行仍不在已通过范围内。
