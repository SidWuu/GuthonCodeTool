# P2 项目总览、当前项目卡片与源码视图

日期：2026-11-19。对应[长期设计 V1.1](long-term-unified-workspace-design.md)的 P2；不包括 P3 旧 provider 执行、P4 配置升级或源码迁移。

## 本地实现

- Nexus 原生侧栏按“项目总览”“当前项目”“当前项目源码”排列。总览消费 P1 的完整 snapshot，保留所有有效模式和配置诊断；可以搜索名称、别名、key，添加或刷新项目。搜索不改变当前操作目标。
- 当前窗口选择覆盖 API、SVN、DATABASE。API 项目继续使用既有卡片、源码树和 SCM；旧模式显示名称、模式、目录与未接入提示，仅提供配置检查和环境检查，不发起 API 登录、同步或源码编辑。
- 点击有效项目行后联动卡片与源码树，IDE 根目录不变。已打开文件和草稿保留归属，当前选择按原窗口状态恢复；源文件事件和编辑登记继续覆盖已登记 API checkout。
- 配置异常保留可点击项目行。诊断状态清除可操作 key，卡片与源码区显示具体原因及配置检查入口；不会自动选中下一个项目。整份配置不可用时显示全局错误，不继续展示可操作的旧卡片。
- 某个项目本地状态读取失败只影响该项目，其余项目保持可选。源状态不完整或索引监听失败时，不把旧摘要显示成已确认零修改。
- 迟到的卡片、目录和 SCM 结果不能覆盖新选择。切换不会将排队操作改到新项目；旧项目的完成结果可以更新其本地总览摘要。源码过滤保留在所属项目，不串到另一个项目。
- 完整旧 YAML 可由“设置/切换工作空间”连接，前端只识别文件集合，内容仍由后端核验；连接不会创建 JSON、Git 或业务目录。不完整旧配置明确报错。

配置检查入口仅打开当前显式 toolHome 下已有配置文件供用户检查；不自动修复、强制覆盖或修改 provider。当前仍不提供旧模式源码执行与同项目迁移。
